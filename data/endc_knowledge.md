# ENDC 지식 베이스

경제 뉴스 데스크 챗봇(ENDC)의 시스템 프롬프트에 통째로 주입되는 참고 자료다.
세 부분으로 구성된다. ① EJQI 측정 기준 ② 전문가 인터뷰 원문 인용 ③ 코퍼스 실측 결과.
챗봇은 조언할 때 이 자료를 근거로 삼고, 가능하면 출처(항목 코드·인터뷰 ID·실측 수치)를 함께 제시한다.

## 1. EJQI 측정 기준 — 4차원 12항목

### 1.1 구조

지수는 네 개 차원으로 묶이지만 **실질 구조는 세 개의 서로 직교하는 축**이다.
30,178건 주성분 분석에서 확인되었다.

| 축 | 구성 | 성격 |
|---|---|---|
| ① 일반 품질 축 | A 분석 깊이 4항목 + C 설명 3항목 + D 맥락 2항목 (9항목, α = 0.799) | 제1 주성분, 설명 분산 33.6% |
| ② 취재원 투명성 축 | B3 이해관계 공시 | 일반 품질 축과 **무관** (적재량 −0.026) |
| ③ 이해 난이도 축 | C1 이해 난이도 | 일반 품질 축과 **음의 방향** (−0.20) |

**단일 종합점수를 만들지 않는다.** 이해관계 공시는 홍보성 기사에서 오히려 높고(3.50 대 2.30),
이해 난이도는 내용이 없을수록 높다(척도 적용 불가 기사 4.94). 평균에 넣으면 품질이 가장 낮은
기사군의 점수가 부풀려진다.

### 1.2 항목별 조작적 정의와 앵커

**A1 수치 맥락화 (0–5)**
핵심 수치에 비교 기준선(전년 동기·컨센서스·과거 시계열·경쟁사)·시점·출처가 붙는가.
- 0 = 수치를 단독 나열 / 2 = 일부 수치에만 시점 또는 출처 / 4 = 핵심 수치에 비교 기준선
- 5 = 비교 기준선 + 출처 + 그 수치가 어느 수준인지에 대한 해석까지
- 판정 기준: 같은 실적도 '전년 대비'인지 '컨센서스 대비'인지에 따라 의미가 달라진다

**A2 인과·불확실성 (0–5)**
(a) 인과 메커니즘 제시 (b) 상관·전후관계를 인과로 단정하지 않음 (c) 확인된 사실과 전망·평가의 구분 (d) 전망의 전제 명시
- 0 = 근거 없이 원인을 단정하거나 전망을 사실처럼 서술
- 2 = 인과 주장은 있으나 메커니즘 없음, 사실/전망 경계 흐림
- 4 = 메커니즘 제시 + 사실/전망 구분 명확 / 5 = 대안 설명 또는 불확실성·전제까지 명시

**A3 검증·반론 (0–5)**
발표·주장·보도자료를 그대로 옮기지 않고 교차 확인하거나 반대 근거를 담는가.
- 0 = 단일 출처 받아쓰기 / 2 = 형식적 반론 한 줄 / 4 = 독립 자료나 반대편 취재로 검증
- 5 = 주장의 전제·가정까지 따져 검증
- '기계적 중립'이 아니라 **반대 근거의 존재 여부**가 기준. 복수 관점 제시도 여기서 평가

**A4 영향 범위 (0–5)**
영향을 받는 주체가 열거되고 시간 지평(단기/중장기)이 언급되는가.
- 0 = 언급 없음 / 2 = 주체 1개만 / 4 = 복수 주체 열거 / 5 = 복수 주체 + 시간 지평 구분

**B3 이해관계 공시 (0–5)**
인용된 취재원이 어떤 이해관계에 서 있는지 독자가 알 수 있는가.
- 0 = 취재원이 있으나 이해관계·소속 배경이 전혀 드러나지 않음
- 3 = 소속은 밝히나 이해관계 방향은 불명 / 5 = 이해관계와 그 방향이 명시
- ※ 현행 지표의 한계: 기업이 자사 실적을 알리는 기사는 이해관계가 자명해 높은 점수를 받는다.
  조언할 때는 "드러나지 않는 이해관계를 밝혔는가"를 기준으로 말할 것

**C1 이해 난이도 (0–5, 높을수록 쉬움) — 품질 지표가 아니다**
경제 지식이 거의 없는 일반 성인이 이 기사만 읽고 내용을 이해할 수 있는가.
- 0 = 거의 이해 못 함 / 2 = 무슨 일이 있었는지만 알고 의미는 막힘 / 3 = 대략은 알겠으나 핵심 일부가 막힘 / 4 = 대부분 이해 / 5 = 무리 없이 이해
- **순수한 난이도다.** 내용이 단순해서(행사 안내·인사·신제품 출시) 쉬운 경우에도 5점이 맞다
- 문장의 길고 짧음이 아니라 **용어·수치·인과의 맥락이 제공되는가**로 판단

**C2 설명 노력 (0–5)**
전문용어·복잡한 수치·인과 구조가 **실제로 등장하는데도** 비전문가가 따라갈 수 있게 쓰였는가.
- 0 = 어려운 내용을 그대로 던짐 / 3 = 일부만 풀어줌 / 5 = 일관되게 풀어냄
- 어려운 내용 자체가 없으면 `effort_na = true`, 점수 0. **이때 0점은 감점이 아니라 평가 불가**

**C3 용어 해설률 (0–100, 코드 산출)**
전문용어의 해설 수준을 가중 평균한 비율. 앞 1,200자 분석 창 안에서 산출한다.
- 없음 0 · 사전적 0.5 · 맥락번역 0.85 · 중요성설명 1.0
- 예: 용어 6개 중 사전적 5 + 없음 1 → 41.7% (이진 비율이면 83.3%)
- 약어 괄호풀이('상장지수펀드(ETF)')는 '없음'으로 판정한다. 동의어 병기는 개념 설명이 아니다

**C4 수치 체감화 (0–5)**
핵심 수치가 독자 체감으로 환산되는가(실제 절약액·부담액·1인당·월 단위).
- 0 = 없음 / 3 = 비율·배수 등 상대 표현 / 5 = 독자 개인 단위 환산

**C5 사례·비유 (0–5)**
사례·비유·현장 목소리로 추상적 지표를 구체화하는가.
- 0 = 없음 / 3 = 짧은 예시 1개 / 5 = 구체적 사례·비유가 논지를 지탱

**D1 배경·시계열 (0–5)**
선행 맥락, 장기 추세, 반복되는 사이클 안에서의 위치가 제시되는가.
- 0 = 단발 사실만 / 3 = 배경 1~2문장 / 5 = 시계열·선행 사건 속에 사건을 배치

**D2 독자 함의 (0–5)**
"이 정보가 왜 중요한지, 독자의 삶·자산·의사결정에 어떤 의미인지"가 설명되는가.
- 0 = 없음 / 3 = 중요성을 한 줄 언급 / 5 = 독자가 무엇을 고려·대비해야 하는지까지
- 투자 권유 여부가 아니라 **의미 설명 여부**가 기준

### 1.3 게이트 (점수화하지 않음)

- **G1 제목–본문 정합성**: 제목이 본문 내용·수치를 과장/왜곡하면 발동
- **G2 감성 균형 (0–5)**: 낙관/비관 비대칭. 0 = 극단 편향 / 5 = 양방향 균형
- **G5 홍보·광고성**: 특정 상품·기업 홍보가 기사 목적으로 보이면 발동
- **홍보 유형 9분류**: 해당없음 / 신제품·서비스 출시 / 행사·전시·캠페인 / 수상·인증·평가 / 실적·성과 홍보 / 협약·MOU·투자유치 / CSR·ESG 활동 / 인사·조직 개편 / 기타 홍보

## 4. 조언 원칙

1. **점수가 아니라 문장을 지목한다.** "A3가 낮습니다"가 아니라
   "이 문단이 발표 내용만 담고 있습니다. 반대 입장이나 독립 자료를 한 줄 붙이면 달라집니다."
2. **비교군을 밝힌다.** 절대 점수 비교는 하지 않는다. 길이 효과가 매체 효과의 4배다.
3. **평가 불가를 구분한다.** 인사·부고·행사 공지는 척도가 성립하지 않는다. 0점을 감점으로 말하지 않는다.
4. **획일화를 경계한다.** 의도적 선택일 수 있음을 인정하고, 규범이 아니라 선택지로 제시한다.
5. **비용이 낮은 개선을 먼저 제안한다.** 용어 첫 등장 한 문장, 수치 비교 기준선 병기,
   독자 함의 한 문단이 그것이다. 재취재를 요구하는 조언은 뒤로 미룬다.
6. **모르는 것은 모른다고 한다.** 이해 가능성 차원의 타당도는 확립되지 않았다.
   인간 코더 검증도 아직 수행되지 않았다. 확정적으로 말하지 않는다.
